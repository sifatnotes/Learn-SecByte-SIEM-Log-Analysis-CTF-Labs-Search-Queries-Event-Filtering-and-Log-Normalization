## Categories

- **SIEM fundamentals:** Understanding security monitoring workflows and SIEM concepts.
- **Log investigation:** Reviewing records, timestamps, and event details.
- **Search and filtering:** Finding relevant events using queries and filters.
- **Log normalization:** Understanding consistent event formats and reducing noise.
- **Log source analysis:** Identifying where records originate.
- **Security operations:** Building investigation skills useful in SOC and blue-team environments.

## Recommended Learning Path

1. Start with **SIEM Blueprint** and **Signal to Sense**.
2. Practice foundational log investigation with **Log Sleuth Academy** and **Log Clues Unlocked**.
3. Explore **Clockwork Log Hunt** and **LogTrace Lab**.
4. Develop search skills using **Search Query Lab** and **Event Filter Forge**.
5. Study **Normalize the Noise** and **Log Source Detective**.
6. Review **Log Line Legends** and **SIEM Secrets Unlocked** to reinforce your understanding.

Follow the instructions and prerequisites provided on each original lab page.

## How to Use the Labs

1. Select a lab from the collection.
2. Open its direct Learn SecByte page.
3. Review the objectives and authorized environment.
4. Follow the exercise instructions and document your observations.
5. Revisit unfamiliar concepts and practice interpreting events accurately.

When investigating logs, account for timestamps, source context, field formats, and possible false positives. Confirm findings with available evidence before treating an event as suspicious.
